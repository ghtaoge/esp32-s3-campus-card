# PC 校园卡控制台

在工程根目录运行 `python tools/serve_pc.py --no-browser`，使用桌面 Chrome / Edge 打开 `http://127.0.0.1:8765/`。也可运行 `tools/start-pc.ps1`。页面从同一服务器加载白名单共享模块 `/shared/`，不使用 `file://`。

- **USB 串口连接**：选择开发板，按 115200 波特率交换逐行 JSON。
- **蓝牙连接**：适用于电池供电，使用 Web Bluetooth 与相同 BLE 服务；需要浏览器和系统支持。
- **体验演示设备**：本机独立数据，A 卡预置 50 元，B 卡为空白。提交业务后点击“刷演示卡”才执行。诊断页可模拟中断，重新刷原卡恢复同一交易。

业务、流水、商品配置、屏幕与电源、诊断分别在侧栏中。未确认交易会锁住新的开卡/充值/消费；原订单恢复保留编号和原始字段。CSV 导出当前筛选的记录，统计只计算成功交易。没有电压采样时显示“电量采样未配置”。

运行 PC 纯逻辑和浏览器接口模拟测试：`node --test pc/tests/*.test.js`。这些测试不代替 Web Serial、Web Bluetooth 与实体卡的实测。
