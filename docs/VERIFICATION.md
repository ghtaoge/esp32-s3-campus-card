# 软件验证记录

日期：2026-11-07（Asia/Shanghai）。

- PlatformIO `esp32-s3-n16r8` 构建成功，Arduino-ESP32 3.3.12；应用程序约 1.06 MiB，静态 RAM 约 40.5 KiB。精确大小以本次构建输出为准，运行时 BLE、堆和 32KB loop 栈另计。
- 小程序与 PC 共 75 项 JavaScript 测试通过，无跳过；包括本机微信官方 WXML 编译器的实际模板编译与渲染条件检查，WXSS 编译检查也通过。
- C++ 核心测试通过：充值消费、余额不足、逐块写入失败、90 种按字节撕裂写、卡已写但回读失败、流水提交失败、重启恢复、原订单幂等、取消、超时、存储失败退避、双端共用一个等待任务、旧快照回放。持久化 State 仍为 4128 字节、版本 1。
- BLE C++ 分包边界、UTF-8 字节跨包、顺序和超时测试通过。
- OLED 主机计数和时序测试通过：静态无重复发送、动画相位、650ms 边界、像素缓存、睡眠/唤醒、亮度与省电；这些是假接口计数，不是实体屏幕帧率。
- 运行时 I/O 测试通过：有界队列、消息不交错、短帧超时恢复、USB 行溢出与短暂掉线/计时回绕、日志双通道快照、闲置熄屏策略。
- 本地 HTTP 服务 4 项测试通过，包括允许的静态/共享文件、8 类越界或私有路径拒绝、外来 Host 拒绝、请求日志不记录查询参数。PC 控制台默认使用18765端口，避免与常见的其它本地设备控制服务混用。
- Edge 浏览器完成演示端到端操作：A 卡 50−12.50+20=57.50；B 卡开卡后拒绝超额消费，10−3=7；两卡余额隔离；6 条记录分页、筛出 B 卡 4 条并导出 CSV；商品/档位编辑、32 像素预览、电池设置与唤醒。1280px 和 390px 布局检查通过，控制台无错误。
- `tools/build.ps1` 默认构建与导出固件成功，没有执行上传。

本机全局 PlatformIO 工具链缺少部分 ESP32-S3 标准库，构建采用已存在的完整本地包缓存。缓存路径仅保存在忽略提交的 `.local/platformio-packages.txt`；构建脚本读后临时设置进程环境，结束时恢复。普通完整的 PlatformIO 安装无需此文件。
